# Security policy

## Supported versions

Only the latest release receives fixes. Update an installed copy with `claude plugin update mermaid-inline@mermaid-inline`.

## Reporting a vulnerability

Please report security problems privately, not in a public issue: on this repository's **Security** tab, choose **Report a vulnerability**. Include the plugin version from `claude plugin list`, your Claude Code version from `claude --version`, and the steps or reply text that show the problem.

The README lists everything the plugin runs, reads and writes on your machine, under [What it runs, reads and writes](README.md#what-it-runs-reads-and-writes).
